# Задание 1

Симуляция платформы технической поддержки на Python. Генерирует случайных операторов, пользователей и историю чатов с возможностью выгрузки данных в JSON.

## Структура проекта

```
suptech/
├── support_platform/          # Основной пакет
│   ├── __init__.py            # Экспорт всех публичных классов и функций
│   ├── data.py                # Статические данные (имена, темы, шаблоны)
│   ├── entities.py            # Модели: Person, Operator, User, Chat
│   ├── core.py                # SupportPlatform — управление чатами и статистика
│   ├── generators.py          # Случайная генерация данных
│   └── export.py              # Выгрузка в JSON и консоль
├── demo_chats.py              # Генерация платформы и сохранение в JSON
├── demo_exports_all_types.py  # Демонстрация всех типов выгрузок
├── console_export.py          # Интерактивное консольное меню выгрузок
├── platform_state.json        # Сохранённое состояние платформы
└── exports/                   # Папка с JSON-выгрузками
```

## Быстрый старт

```bash
# 1. Генерация тестовой платформы
python demo_chats.py

# 2. Все выгрузки автоматически
python demo_exports_all_types.py

# 3. Интерактивное меню
python console_export.py
```
